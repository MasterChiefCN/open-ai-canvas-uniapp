# Open AI Canvas UniApp

面向 [Open AI Canvas](https://github.com/ddcat-ai/open-ai-canvas) 的独立微信小程序前端，使用 uni-app 实现移动端账号、AI 创作、任务和积分体验。

**当前状态：文档初始化，尚未生成可运行的小程序工程。** 以下是首版范围与工程约定，不是已完成功能清单。暂不提供安装、开发和构建命令；工程建立后将补充已验证的操作步骤。

## 项目目标

- 编译目标为微信小程序，计划使用 uni-app + Vue 3 + TypeScript + Pinia。
- 复用现有 Open AI Canvas 后端，不要求修改后端业务代码。
- 参照现有 Web 账号页、创作首页、`/tasks` 和 `/wallet`，制作适合手机的交互。
- 对接兼容后端时，业务地址只在一个配置文件修改。
- 同一后端下共享账号、生成任务和积分数据。

本项目不依赖新增 uniCloud 服务或独立转发后端，也不通过 web-view 嵌入原网站。

## 首版范围

| 模块 | 计划功能 |
| --- | --- |
| 账号 | 用户名/邮箱密码登录、注册、邮箱验证码、找回密码、会话恢复、退出登录 |
| 创作 | 视频、图片、文本；模型选择；能力驱动参数；参考图；生成进度与结果 |
| 任务 | 最近任务、状态/类型筛选、详情、日志、预览、取消和重试 |
| 积分 | 可用余额、预占说明、兑换码兑换、分页积分流水 |

底部导航为 **创作 / 任务 / 积分**，退出登录位于首页账号菜单。

首版不包含微信一键登录、第三方 OAuth、在线充值/支付、签到入口、音频生成、独立素材库、项目/分镜管理、无限画布、Agent、剪辑或后台管理。

### 账号页

沿用现有 Web 的深色卡片、登录/注册切换、白色主按钮和密码显隐。小屏调整为单列表单，保留原字段：

- 登录：用户名或邮箱、密码、忘记密码入口。
- 注册：用户名、显示名称、邮箱、邮箱验证码、密码、确认密码。
- 找回：绑定邮箱、验证码、新密码、确认密码。

用户名仍为独立必填字段，不能使用邮箱直接替代。注册与邮件可用性由后端设置决定。

### 创作首页

视频、图片、文本三种模式共用输入与结果区域。模型、比例、时长、分辨率、质量和参考图能力来自后端模型目录，只展示当前模型支持的选项。

生成任务在后端执行。离开页面或将小程序切入后台后，前端暂停查询；返回时恢复状态。文本首版采用增量轮询，媒体结果采用后端短期签名地址预览和保存。

### 任务与积分

任务页采用卡片列表，展示类型、模型、提示词、时间、状态和进度，详情中查看结果和日志。重试与取消按后端状态开放。

积分页仅提供余额、兑换与流水。积分内部使用 microcredits 整数，显示时按 `1 积分 = 1,000,000 microcredits` 转换；最终扣费及退款以服务端账务为准。

## 后端对接：业务地址只改一处

工程实现时，唯一业务后端配置文件为 `src/config/backend.ts`，拟定内容：

```ts
export const backendConfig = Object.freeze({
  apiBaseUrl: 'https://your-domain.example/api',
});
```

将该地址替换为自己的 HTTPS API 根地址并重新编译。地址包含 `/api`，不带尾部斜杠。

所有普通请求、上传、媒体地址请求和任务查询使用此配置。页面只调用业务服务，不硬编码域名；不再设置第二套 `.env` 地址覆盖或默认公共后端。

**“只改一处”指小程序业务后端地址，不代表微信平台部署没有其他设置。**

| 设置 | 位置 |
| --- | --- |
| 兼容后端 API 地址 | 拟建的 `src/config/backend.ts` |
| 微信小程序 AppID | 小程序工程/开发者工具配置 |
| request、uploadFile、downloadFile 合法域名 | 微信公众平台 |
| OSS/CDN 域名与 HTTPS 资源地址 | 微信平台及已有后端存储配置 |
| SMTP、注册开放、模型、积分、兑换码 | 已有 Open AI Canvas 管理后台 |

更换后端需要同时满足域名和接口兼容条件；若后端接口或字段被修改，则需更新适配器，不能仅靠更换地址解决。

## 架构约定

```text
页面 / 组件
    ↓
状态管理 / 业务服务
    ↓
业务 API / Open AI Canvas 数据适配器
    ↓
统一请求、会话、资源地址与缓存
    ↓
既有 Open AI Canvas 后端
```

计划目录职责：

| 路径 | 职责 |
| --- | --- |
| `src/config/backend.ts` | 单一后端配置入口 |
| `src/core/` | 请求、Cookie、URL 与账号隔离存储 |
| `src/api/` | auth、models、tasks、resources、wallet 接口 |
| `src/adapters/open-ai-canvas/` | 后端特有的生成入参、结果与能力映射 |
| `src/services/` | 生成编排、共享轮询、媒体处理 |
| `src/stores/` | 用户、模型、创作、任务、积分状态 |
| `src/pages/`、`src/components/` | 小程序页面与复用 UI |
| `docs/` | 后续部署、兼容与验收说明 |

这些目录将在工程搭建时按需创建。接口 DTO、纯业务逻辑可以参考上游；React、Ant Design 和浏览器专用存储不能直接移植到小程序。

## 接口范围

以下均为相对于 API 根地址的现有接口，本版核心功能只需 GET/POST：

| 用途 | 方法与路径 |
| --- | --- |
| 认证配置 | GET `/auth/settings` |
| 登录 / 注册 | POST `/auth/login`、`/auth/register` |
| 注册验证码 | POST `/auth/email-code` |
| 找回密码 | POST `/auth/password-reset-code`、`/auth/password-reset` |
| 会话 / 退出 | GET `/auth/session`、POST `/auth/logout` |
| 模型 | GET `/model-catalog`、POST `/model-catalog/available` |
| 上传 / 媒体地址 | POST `/resources`、GET `/resources/:id/oss-url` |
| 创建 / 查询任务 | POST `/tasks`、GET `/tasks`、GET `/tasks/:id` |
| 文本增量 / 日志 | GET `/tasks/:id/text-deltas`、GET `/tasks/:id/logs` |
| 取消 / 重试 | POST `/tasks/:id/cancel`、POST `/tasks/:id/retry` |
| 余额与流水 / 兑换 | GET `/wallet`、POST `/wallet/redeem` |

登录接口的 `username` 字段既可以传用户名，也可以传邮箱。小程序将适配现有 Cookie 会话，不要求后端增加 JWT。

## 兼容性与已知边界

- 静态分析基线为上游 [`9868f5e8`](https://github.com/ddcat-ai/open-ai-canvas/tree/9868f5e8)。尚未完成真实接口与微信真机联调，不宣称支持所有历史或未来版本。
- 任务列表接口最多返回最近 100 条，没有完整历史分页。客户端筛选和统计仅针对已加载任务；积分流水则支持真实分页。
- 创作草稿和会话分组计划保存在小程序本地并按账号隔离，不承诺与 Web 首页会话分组双向同步。
- 生成结果可查看或保存，不代表已经完成 Web 素材库的业务入库和画布关联。
- 媒体签名地址可能过期，需要重新获取。小程序上传、下载及播放需满足实际域名和格式要求。
- 生成或兑换请求超时可能已经被后端接受，不能自动重复提交。
- Cookie、请求、上传和后台恢复必须进行微信真机验证，不能以 H5 可用代替小程序可用。

## 开发路线

1. 初始化工程、统一配置、请求与会话层。
2. 实现账号页面并验证注册、登录、找回和会话恢复。
3. 实现模型选择、参考图上传和文本/图片/视频生成。
4. 实现任务页、详情与前后台恢复。
5. 实现积分余额、兑换和流水。
6. 完成微信 iOS/Android 真机回归，补充可复现的开发、构建与部署文档。

功能是否完成，以实际代码和验收记录为准。当前仅完成项目约定与首版 README。
